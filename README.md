## 📖 About

MyPaint is an open source raster graphics editor maintained by a community of developers and artists. It is designed around the needs of painters rather than photo editors, with an infinite canvas, pressure sensitive brush dynamics, and a brush engine that responds naturally to stylus input. The 2026 build focuses on stability on Windows 10 and 11, faster brush loading, and smoother performance on high DPI displays. It works well for sketching, illustration, concept art and matte painting.

If you came looking for a MyPaint download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The build is a standard Windows installer, so setup is straightforward and does not require any additional runtime downloads in most cases.

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without finishing | Restart Windows and run the setup file again from the Downloads folder. |
| App opens but no canvas appears | Update your graphics driver, then relaunch MyPaint. |
| Stylus pressure not detected | Install the tablet manufacturer driver and recheck the tablet settings. |
| Brush strokes lag on large canvases | Lower the brush size or reduce the number of active layers. |
| Canvas renders at the wrong scale | Adjust the display scaling setting in Windows and restart the app. |
| Settings or brushes seem missing | Check that the app has write access to your user profile folder. |
